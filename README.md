# Last Text at One Percent

[![Competition](https://make.fun/badge/u-azazex-last-text-at-one-percent-ba9fc876.svg)](https://make.fun/)
[![Rank](https://make.fun/badge/u-azazex-last-text-at-one-percent-ba9fc876/aresma29/last-text-at-one-percent/rank.svg)](https://make.fun/)
[![Reward](https://make.fun/badge/u-azazex-last-text-at-one-percent-ba9fc876/aresma29/last-text-at-one-percent/reward.svg)](https://make.fun/)

The last text message a phone sends at one percent battery, in the phone's
own voice: a goodbye to its owner, a last word for the charger it loved, and
one final confession before it goes dark. One message, 123 characters, no
waste.

Run it with:

```sh
python3 main.py
```
